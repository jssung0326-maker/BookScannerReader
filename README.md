# BookScannerReader v0.5

iPhone용 **책 전용 스캐너 + OCR + 검색 가능한 PDF + Reader** 프로토타입입니다.

## v0.5 핵심 변경 사항

- **페이지 관리 화면 추가**
  - 페이지 썸네일과 OCR 일부 내용을 목록으로 확인
  - 편집 모드에서 페이지 순서 변경
  - 개별 페이지 삭제
  - 개별 페이지 좌/우 90° 회전
  - 특정 페이지만 다시 촬영하여 교체
- **페이지 재촬영 후 자동 처리**
  - 기존 책의 `ScanProfile`을 재사용
  - 원근/제본부/곡면 보정 설정을 재적용
  - 기준 페이지 규격으로 다시 정규화
  - OCR을 다시 실행하고 PDF 재생성
- **책 전체 OCR 검색**
  - 리더 화면에서 돋보기 버튼으로 OCR 전체 검색
  - 검색 결과에서 해당 페이지로 바로 이동
- **PDF 페이지 이동과 읽던 위치 저장 개선**
  - PDFKit 페이지 변경과 SwiftUI 페이지 번호를 동기화
  - 책을 닫을 때 현재 읽던 페이지를 저장
- **검색 가능한 PDF 1차 구현**
  - 스캔 이미지와 OCR 텍스트를 같은 PDF에 기록
  - PDF 내부 검색/텍스트 추출을 위한 숨은 텍스트 레이어 추가
  - v0.5에서는 검색 가능성을 우선하며, OCR 글자 위치와 이미지 글자 위치의 정밀 매핑은 후속 버전에서 개선 예정
- **촬영 품질 검사 1차 구현**
  - 지나치게 어두움/밝음
  - 낮은 대비
  - 심한 흐림 가능성
  - 문제가 의심되면 자동 폐기하지 않고 `계속 진행 / 다시 촬영`을 사용자가 선택
- 버전 `0.5`, 빌드 `5`

## 기존 기능

- 서재(책 목록)
- VisionKit 문서 스캔
- 1페이지 / 펼친 2페이지 촬영 모드
- 펼친 책 좌/우 페이지 자동 분리
- 제본선 자동 검출 및 수동 위치 설정
- 왼쪽→오른쪽 / 오른쪽→왼쪽 읽기 순서
- 좌/우 페이지 독립 원근 보정
- 제본부 그림자/검은 여백 자동 제거
- 곡면(dewarp) 1차 보정 및 강도 조절
- 첫 페이지 비율을 기준 규격으로 저장
- 이후 모든 페이지 동일 크기로 정규화
- 한국어/영어 OCR
- 스캔 이미지 → PDF 생성
- 기존 PDF 가져오기
- PDFKit 기반 Reader
- OCR 텍스트 음성 읽기(TTS)
- 사용자 책 데이터는 앱 Documents 폴더에 저장하여 Git 저장소와 분리

## v0.5 사용 흐름

```text
책 스캔
  → 촬영 품질 1차 검사
  → 1페이지 또는 펼친 2페이지 분리
  → 원근/제본부/곡면 보정
  → 기준 페이지 규격으로 통일
  → OCR
  → 검색 가능한 PDF 생성
  → 서재 등록

책 읽기
  → PDF/스캔 페이지 보기
  → OCR 전체 검색
  → 해당 페이지 이동
  → 현재 페이지 읽어주기
  → 읽던 위치 자동 저장

페이지 수정
  → 페이지 관리
  → 순서 변경 / 삭제 / 회전 / 개별 재촬영
  → OCR 갱신
  → 검색 가능한 PDF 자동 재생성
```

## 검색 가능한 PDF에 대하여

v0.5는 각 페이지의 스캔 이미지를 PDF에 표시하면서 OCR 텍스트를 보이지 않는 텍스트 객체로 함께 기록합니다.

- PDF 내부 검색을 가능하게 하기 위한 1차 구현
- OCR 텍스트와 실제 이미지 속 글자의 정확한 위치 매핑은 아직 하지 않음
- 따라서 검색은 가능하지만 텍스트를 드래그 선택할 때 이미지 속 글자 위치와 정확히 일치하지 않을 수 있음
- 후속 버전에서는 Vision OCR bounding box를 저장하여 정밀 텍스트 레이어로 발전 예정

## 현재 한계

1. v0.4와 마찬가지로 곡면 보정은 완전한 3D 복원이 아닌 2D 1차 보정입니다.
2. 촬영 품질 검사는 밝기/대비/간단한 경계량을 이용한 보조 검사라 오판 가능성이 있습니다.
3. 손가락 자동 제거, 페이지 넘김 자동 감지, 자동 촬영은 아직 미구현입니다.
4. PDF OCR 텍스트 레이어는 검색 우선 1차 구현이며 정확한 글자 위치 매핑은 후속 버전에서 개선합니다.
5. 첫 사진만으로 실제 종이의 정확한 mm 크기는 알 수 없습니다. 현재는 첫 페이지 비율과 기준 픽셀 폭을 사용합니다.
6. 실제 iPhone 설치/서명 검증은 macOS + Xcode가 필요합니다. GitHub Actions에서는 Simulator 빌드 검사를 수행합니다.

## GitHub 업데이트 방법

현재 v0.4 저장소에 v0.5 압축을 푼 뒤 아래 항목을 다시 업로드합니다.

```text
App/
Models/
Services/
Utilities/
Views/
Resources/
BookScannerReader.xcodeproj/
README.md
.gitignore
```

`.github/workflows/ios-build.yml`은 기존과 동일하므로 다시 업로드하지 않아도 됩니다.

### 커밋 메시지 바꾸기

GitHub 웹의 `Add file → Upload files`에서 파일을 올리면 화면 아래 `Commit changes` 영역의 첫 번째 입력칸에 보통 `Add files via upload`가 자동으로 들어갑니다.

그 문장을 지우고 아래처럼 직접 입력한 뒤 `Commit changes`를 누릅니다.

```text
Update BookScannerReader to v0.5
```

이미 완료된 과거 커밋의 메시지를 웹에서 굳이 다시 바꿀 필요는 없습니다. 앞으로 업로드할 때 커밋하기 전에 메시지만 바꾸는 방식이 가장 간단합니다.

업로드 후 **Actions → iOS Build Check**가 초록색인지 확인합니다.
