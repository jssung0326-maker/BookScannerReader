# BookScannerReader v0.4

iPhone용 **책 전용 스캐너 + OCR + PDF Reader** 프로토타입입니다.

## v0.4 핵심 변경 사항

- 제본선 자동 검출 알고리즘 개선
  - 중앙부 밝기만 보던 v0.3 방식에서 **밝기 + 좌우 대비 + 중앙 우선도 + 텍스처 패널티**를 함께 사용
  - 어두운 제본선뿐 아니라 밝은 페이지 사이의 수직 경계도 후보로 평가
  - 후보가 약하면 안전하게 50% 중앙값 사용
- 페이지 외곽/원근 보정 강화
  - 한 개 사각형만 쓰지 않고 최대 8개 후보를 검출
  - **면적 + 화면 중앙 정렬 + Vision 신뢰도**로 가장 가능성 높은 페이지 외곽 선택
- 펼친 책의 좌/우 페이지를 각각 독립 보정
- 제본부 그림자/검은 여백 자동 제거
  - 좌측 페이지는 오른쪽 안쪽 가장자리, 우측 페이지는 왼쪽 안쪽 가장자리를 분석
  - 필요할 때만 최대 약 7% 범위에서 자동 제거
- **곡면(dewarp) 보정 1차 구현**
  - 제본부 가까운 영역을 가볍게 비선형 수평 보정하여 글자가 안쪽으로 눌려 보이는 현상을 완화
  - 보정 강도 0~100% 조절 가능
  - 완전한 3D 책 곡면 복원은 아니며, 안전한 2D 1차 보정
- 스캔 화면에 페이지 보정 설정 추가
  - 페이지 경계·원근 자동 보정 ON/OFF
  - 제본부 그림자 자동 제거 ON/OFF
  - 곡면 보정 강도 조절
- v0.2 / v0.3 `ScanProfile` 하위 호환 유지
- 버전 `0.4`, 빌드 `4`

## 기존 기능

- 서재(책 목록)
- VisionKit 문서 스캔
- 1페이지 / 펼친 2페이지 촬영 모드
- 2페이지 촬영본 좌/우 독립 페이지 분리
- 자동/수동 제본선 설정
- 왼쪽→오른쪽 / 오른쪽→왼쪽 페이지 순서
- 첫 페이지 비율을 기준 규격으로 저장
- 이후 페이지를 동일 출력 크기로 정규화
- 한국어/영어 OCR
- 스캔 이미지 → PDF 생성
- 기존 PDF 가져오기
- PDFKit 기반 PDF Reader
- OCR 텍스트 음성 읽기(TTS)
- 사용자 책 데이터는 앱 Documents 폴더에 저장하여 Git 저장소와 분리

## v0.4 스캔 흐름

```text
책 만들기
  → 1페이지 / 2페이지 촬영 선택
  → 페이지 보정 옵션 설정
  → VisionKit으로 연속 촬영
  → 2페이지 모드: 개선된 제본선 자동 검출 또는 수동 분리선
  → 좌/우 페이지 분리
  → 페이지 외곽 후보 검출 및 원근 보정
  → 제본부 그림자/검은 여백 자동 제거
  → 곡면 보정 1차 처리
  → 첫 페이지 비율을 기준 규격으로 저장
  → 모든 페이지 동일 규격으로 정규화
  → OCR
  → PDF 생성
  → 서재 등록
```

## 곡면 보정에 대하여

v0.4의 곡면 보정은 제본부에서 글자가 수평으로 눌리는 현상을 줄이기 위한 **1차 2D 비선형 리매핑**입니다.

- 기본 강도: 35%
- 과하게 늘어나 보이면 강도를 낮춰 사용
- 완전한 3D dewarp(글줄의 상하 휘어짐까지 복원)는 후속 버전에서 고도화 예정

## 현재 한계

1. 페이지가 손이나 물체에 크게 가려진 경우 외곽 검출이 틀릴 수 있습니다.
2. v0.4 곡면 보정은 1차 방식이며, 실제 책의 3D 곡률을 추정하는 방식은 아닙니다.
3. 손가락 제거, 흔들림/초점 품질 검사, 페이지 넘김 자동 감지, 자동 촬영은 아직 미구현입니다.
4. 첫 사진만으로 실제 종이의 정확한 mm 크기를 알 수는 없습니다. 현재는 첫 페이지 비율과 기준 픽셀 폭을 사용합니다.
5. 생성 PDF는 현재 이미지 기반 PDF입니다. OCR 텍스트를 PDF 검색용 숨은 텍스트 레이어로 삽입하는 기능은 후속 버전에서 추가할 예정입니다.
6. 실제 iPhone 빌드/서명 검증은 macOS + Xcode가 필요합니다. GitHub Actions에서는 Simulator 빌드 검사를 수행합니다.

## GitHub 업데이트 방법

현재 v0.3 저장소에 v0.4 압축을 푼 뒤 아래 항목을 다시 업로드합니다.

```text
App/
Models/
Services/
Utilities/
Views/
Resources/
BookScannerReader.xcodeproj/
README.md
.gitignore
```

`.github/workflows/ios-build.yml`은 기존과 동일하므로 다시 만들 필요가 없습니다.

업로드 후 `Commit changes`를 누르고 **Actions → iOS Build Check**가 초록색인지 확인합니다.

권장 커밋 메시지:

```text
Update BookScannerReader to v0.4
```
