# BookScannerReader v0.8

iPhone용 **책 전용 스캐너 + OCR + 검색 가능한 PDF + Reader + 음성 독서** 프로토타입입니다.

## v0.8 핵심 변경 사항

- **스캔 세션 이어하기**
  - 이미 만든 스캔 책의 `페이지 관리` 화면에서 카메라 버튼으로 이어서 촬영 가능
  - 기존 책의 `ScanProfile`을 그대로 재사용
  - 1페이지/2페이지 촬영 방식, 읽기 순서, 제본선 자동 검출, 원근 보정, 곡면 보정, 기준 페이지 크기를 그대로 적용
  - 새 페이지는 기존 마지막 페이지 뒤에 자동 번호를 붙여 저장
  - 이어 스캔 후 OCR 및 검색 가능한 PDF를 자동으로 다시 생성
- **중복 페이지 감지 1차 구현**
  - 이어 스캔 경계에서 직전 페이지를 다시 찍는 실수를 자동 검사
  - OCR 텍스트 유사도를 우선 사용하고, 텍스트가 거의 없는 페이지는 매우 높은 이미지 유사도만 보조적으로 사용
  - 중복으로 판단된 페이지는 이어 스캔 결과에서 제외하고 제외 수를 사용자에게 알림
  - 같은 촬영 배치 안에서도 직전 새 페이지들과 비교하여 반복 촬영을 줄임
- **촬영 품질 검사 강화**
  - 밝기, 대비, 엣지 에너지를 이용한 기존 검사 유지
  - `0~100` 품질 점수를 함께 계산
  - 품질 문제가 있으면 이어 스캔에서도 `계속 추가 / 다시 촬영 / 취소` 선택 가능
- **연속 촬영 작업 흐름 개선**
  - VisionKit 문서 카메라의 다중 페이지 촬영 결과를 한 번에 이어서 처리
  - 2페이지 모드에서는 각 촬영본을 좌/우 페이지로 자동 분리한 뒤 동일 규격으로 정규화
  - 작업 중 처리 상태(분리/보정/OCR/PDF 재생성)를 화면에 표시
- 앱 버전 `0.8`, 빌드 `8`

## v0.8 이어 스캔 흐름

```text
기존 스캔 책 열기
  → 페이지 관리
  → 카메라(이어 스캔)
  → 여러 장 연속 촬영
  → 촬영 품질 검사
  → 1페이지/2페이지 분리 + 원근/곡면 보정
  → 기존 책의 기준 크기로 정규화
  → OCR
  → 직전 페이지와 중복 여부 검사
  → 새 페이지만 기존 마지막 페이지 뒤에 추가
  → 검색 가능한 PDF 자동 재생성
```

- VisionKit 문서 스캔
- 1페이지 / 펼친 2페이지 촬영 모드

- 제본선 자동 검출 및 수동 위치 설정
- 왼쪽→오른쪽 / 오른쪽→왼쪽 읽기 순서
- 좌/우 페이지 독립 원근 보정
- 제본부 그림자/검은 여백 자동 제거
- 곡면(dewarp) 1차 보정 및 강도 조절
- 첫 페이지 비율을 기준 규격으로 저장
- 이후 모든 페이지 동일 크기로 정규화
- 한국어/영어 OCR
- 촬영 품질 검사
- 페이지 썸네일 관리
- 페이지 순서 변경 / 삭제 / 회전
- 특정 페이지만 재촬영/교체
- 스캔 이미지 → 검색 가능한 PDF 생성
- 기존 PDF 가져오기
- PDFKit 기반 Reader
- PDF 세로 스크롤 / 가로 페이지 넘김
- 페이지 직접 이동
- 북마크 / 페이지 메모
- OCR/PDF 전체 검색
- PDF 공유/내보내기
- 현재 페이지/책 끝까지 음성 읽기
- 일시정지/이어읽기/속도 조절
- 최근 읽은 책 및 읽기 진행률
- 사용자 책 데이터는 앱 Documents 폴더에 저장하여 Git 저장소와 분리

## 데이터 호환

v0.8은 v0.7의 저장 형식을 그대로 사용합니다. 기존 `Library.json`, `pages.json`, 이미지 및 PDF를 삭제할 필요가 없습니다.

## 현재 한계

1. v0.8의 중복 감지는 OCR 텍스트 및 정규화 이미지 유사도를 이용한 **보조 판정**입니다. 내용이 거의 같은 서식 페이지에서는 오판 가능성이 있습니다.
2. `페이지가 실제로 넘어가는 순간`을 라이브 카메라 프레임에서 직접 감지하는 기능은 아직 아닙니다. 촬영이 끝난 뒤 반복 페이지를 검사합니다.
3. 현재 카메라는 `VNDocumentCameraViewController`를 사용합니다. 문서 경계/촬영 UI는 VisionKit이 담당하며, 앱 자체의 실시간 안정도 기반 셔터 제어는 후속 단계입니다.
4. 이미지형 외부 PDF에 텍스트 레이어가 없으면 검색/음성 읽기를 위한 PDF 전체 OCR 재처리가 필요합니다. 후속 버전에 추가할 예정입니다.
5. 곡면 보정은 완전한 3D 복원이 아닌 2D 1차 보정입니다.
6. 실제 iPhone 설치/서명 검증은 macOS + Xcode가 필요합니다. GitHub Actions에서는 Simulator 빌드 검사를 수행합니다.

## GitHub 업데이트 방법

v0.7 저장소에 v0.8 압축을 푼 뒤 아래 항목을 다시 업로드합니다.

```text
App/
Models/
Services/
Utilities/
Views/
Resources/
BookScannerReader.xcodeproj/
README.md
.gitignore
```

`.github/workflows/ios-build.yml`은 기존과 동일하므로 다시 업로드하지 않아도 됩니다.

커밋 메시지:

```text
Update BookScannerReader to v0.8
```

업로드 후 **Actions → iOS Build Check**가 초록색인지 확인합니다.
