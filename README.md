# BookScannerReader v0.6

iPhone용 **책 전용 스캐너 + OCR + 검색 가능한 PDF + Reader** 프로토타입입니다.

## v0.6 핵심 변경 사항

- **PDF Reader 기능 강화**
  - `세로 스크롤` / `가로 페이지 넘김` 보기 방식 전환
  - 현재 읽던 페이지를 이동할 때마다 저장
  - 페이지 번호 직접 입력 이동
  - 스캔 PDF와 가져온 PDF 모두 같은 Reader 흐름으로 사용
- **북마크 추가**
  - 현재 페이지 북마크 추가/해제
  - 북마크 목록에서 해당 페이지로 바로 이동
  - 서재 목록에 북마크 개수 표시
  - 페이지 순서 변경/삭제 시 스캔 페이지 북마크 위치도 함께 정리
- **PDF 전체 검색 확대**
  - 스캔 책은 OCR 텍스트에서 검색
  - 외부에서 가져온 일반 PDF는 PDFKit 텍스트에서 검색
  - 검색 결과를 누르면 해당 페이지로 바로 이동
- **PDF 공유/내보내기**
  - Reader 메뉴에서 현재 PDF를 파일 앱, AirDrop, 메신저 등 iOS 공유 시트로 전달 가능
- **검색 가능한 PDF 2차 구현**
  - Vision OCR 결과의 bounding box를 `PageRecord`에 저장
  - OCR 문장 위치를 이용해 숨은 PDF 텍스트 레이어를 배치
  - v0.5의 전체 텍스트 1개 레이어보다 실제 이미지 글자 위치와 더 가깝게 매핑
  - v0.5 이하 데이터는 bounding box가 없어도 기존 방식으로 계속 PDF 생성 가능
- **PDF 메타데이터**
  - 스캔 PDF 생성 시 책 제목/저자를 PDF 메타데이터에 반영
  - 외부 PDF 가져오기 시 PDF에 제목/저자가 있으면 서재 정보에 사용
- **버전 정보 정리**
  - 앱 버전 `0.6`, 빌드 `6`
  - `Info.plist`가 Xcode의 `MARKETING_VERSION` / `CURRENT_PROJECT_VERSION`을 사용하도록 수정

## 기존 기능

- 서재(책 목록)
- VisionKit 문서 스캔
- 1페이지 / 펼친 2페이지 촬영 모드
- 펼친 책 좌/우 페이지 자동 분리
- 제본선 자동 검출 및 수동 위치 설정
- 왼쪽→오른쪽 / 오른쪽→왼쪽 읽기 순서
- 좌/우 페이지 독립 원근 보정
- 제본부 그림자/검은 여백 자동 제거
- 곡면(dewarp) 1차 보정 및 강도 조절
- 첫 페이지 비율을 기준 규격으로 저장
- 이후 모든 페이지 동일 크기로 정규화
- 한국어/영어 OCR
- 촬영 품질 1차 검사
- 페이지 썸네일 관리
- 페이지 순서 변경 / 삭제 / 회전
- 특정 페이지만 재촬영/교체
- 스캔 이미지 → 검색 가능한 PDF 생성
- 기존 PDF 가져오기
- PDFKit 기반 Reader
- OCR/PDF 텍스트 음성 읽기(TTS)
- 사용자 책 데이터는 앱 Documents 폴더에 저장하여 Git 저장소와 분리

## v0.6 사용 흐름

```text
책 스캔
  → 촬영 품질 검사
  → 1페이지 또는 펼친 2페이지 분리
  → 원근/제본부/곡면 보정
  → 기준 페이지 규격으로 통일
  → OCR + 텍스트 위치 저장
  → 검색 가능한 PDF 생성
  → 서재 등록

책 읽기
  → 세로 스크롤 / 가로 페이지 넘김 선택
  → 전체 검색
  → 페이지 직접 이동
  → 북마크
  → 현재 페이지 음성 읽기
  → 읽던 위치 자동 저장
  → PDF 공유/내보내기

외부 PDF
  → 파일 앱에서 PDF 가져오기
  → PDF 제목/저자 메타데이터 읽기
  → 전체 검색 / 북마크 / 페이지 이동 / 음성 읽기
```

## 검색 가능한 PDF 2차 구현

v0.6부터 새로 OCR하는 페이지는 Vision이 반환하는 문장별 bounding box를 저장합니다.

```text
OCRBlock
  text
  x, y
  width, height
```

PDF를 다시 만들 때 이 좌표를 이용해 각 문장 위치에 보이지 않는 텍스트 객체를 배치합니다.

- PDF 검색 가능
- 텍스트 추출 가능
- v0.5보다 이미지 속 글자 위치와 PDF 텍스트 위치가 더 가까움
- 기존 v0.5 책은 다음 재촬영/회전 등으로 OCR을 다시 실행한 페이지부터 좌표 정보가 생김
- 완전한 글자 단위 좌표 매핑은 아직 아님(현재는 문장/라인 단위)

## 데이터 호환

v0.6에서 `Book`과 `PageRecord`에 새 필드가 추가됐지만 이전 버전 데이터를 계속 읽을 수 있도록 기본값을 적용합니다.

- `Book.bookmarkedPageIndices` → 구버전은 `[]`
- `PageRecord.ocrBlocks` → 구버전은 `[]`

따라서 v0.5에서 만든 서재/페이지 데이터를 삭제할 필요가 없습니다.

## 현재 한계

1. 곡면 보정은 완전한 3D 복원이 아닌 2D 1차 보정입니다.
2. OCR 텍스트 위치는 문장/라인 단위라 글자 단위 선택 위치는 완벽하지 않을 수 있습니다.
3. 이미지형 PDF(텍스트 레이어가 없는 외부 PDF)는 가져온 뒤 바로 본문 검색되지 않을 수 있습니다. 추후 PDF OCR 재처리를 추가할 예정입니다.
4. 자동 촬영, 페이지 넘김 감지, 손가락 자동 제거는 아직 미구현입니다.
5. 첫 사진만으로 실제 종이의 정확한 mm 크기는 알 수 없습니다. 현재는 첫 페이지 비율과 기준 픽셀 폭을 사용합니다.
6. 실제 iPhone 설치/서명 검증은 macOS + Xcode가 필요합니다. GitHub Actions에서는 Simulator 빌드 검사를 수행합니다.

## GitHub 업데이트 방법

현재 v0.5 저장소에 v0.6 압축을 푼 뒤 아래 항목을 다시 업로드합니다.

```text
App/
Models/
Services/
Utilities/
Views/
Resources/
BookScannerReader.xcodeproj/
README.md
.gitignore
```

`.github/workflows/ios-build.yml`은 기존과 동일하므로 다시 업로드하지 않아도 됩니다.

커밋 메시지는 아래처럼 입력합니다.

```text
Update BookScannerReader to v0.6
```

업로드 후 **Actions → iOS Build Check**가 초록색인지 확인합니다.
