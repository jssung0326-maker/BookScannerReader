# BookScannerReader v0.9

iPhone용 **책 전용 스캐너 + OCR + 검색 가능한 PDF + Reader + 음성 독서** 프로토타입입니다.

## v0.9 핵심 변경 사항

- **책 전용 커스텀 카메라 1차 구현**
  - `AVFoundation` 기반 자체 카메라 화면 추가
  - 기존 `VisionKit 기본 문서 스캐너`도 선택 가능
  - 새 책은 `책 자동 카메라`를 기본 촬영 방식으로 사용
  - 기존 v0.8 이하 책은 데이터 호환을 위해 기존 문서 스캐너 방식을 그대로 유지
- **실시간 페이지 감지**
  - 라이브 카메라 프레임에서 Vision 사각형 검출 수행
  - 페이지 후보가 잡히면 화면에 초록/노랑/주황 가이드 표시
  - 페이지가 너무 작게 잡히면 가까이 촬영하도록 안내
- **안정도 기반 자동 촬영**
  - 페이지 외곽 위치/크기 변화가 일정 범위 안에서 유지되는 시간을 측정
  - 설정한 최소 품질 점수를 만족하고 지정 시간 동안 안정되면 자동 셔터
  - 자동 촬영 대기 시간 `0.4~1.6초` 조절 가능
  - 최소 품질 점수 `50~85점` 조절 가능
  - 카메라 화면에서 자동 촬영 ON/OFF 전환 가능
  - 언제든 수동 셔터 사용 가능
- **라이브 중복 촬영 억제**
  - 직전 촬영 이미지와 현재 프레임의 이미지 패턴을 비교
  - 같은 페이지가 그대로 보이면 `페이지를 넘겨주세요` 안내
  - 페이지가 바뀐 뒤 다시 안정되면 다음 페이지 자동 촬영
  - v0.8의 OCR + 이미지 기반 후처리 중복 감지도 그대로 유지하여 2중 검사
- **연속 책 스캔 UI**
  - 촬영 장수 실시간 표시
  - 촬영 성공 시 화면 플래시 피드백
  - 페이지/품질/안정 상태 문구 실시간 표시
  - 손전등(낮은 밝기) ON/OFF
  - 여러 장 촬영 후 `완료`를 누르면 기존 분리/보정/OCR/PDF 파이프라인으로 전달
- **이어 스캔 연동**
  - v0.9 새 책은 `페이지 관리 → 이어 스캔`에서도 책 자동 카메라 설정 재사용
  - 책별 자동 촬영 여부, 품질 점수, 안정 대기 시간을 `ScanProfile`에 저장
  - 개별 페이지 재촬영은 실수 방지를 위해 자동 셔터 OFF 상태로 실행
- 앱 버전 `0.9`, 빌드 `9`

## v0.9 자동 촬영 흐름

```text
책 자동 카메라 실행
  → 페이지 외곽 실시간 탐지
  → 페이지 위치/크기 안정도 계산
  → 밝기/대비/선명도 기반 품질 점수 계산
  → 직전 촬영 페이지와 이미지 유사도 검사
  → 새 페이지 + 안정 상태 + 최소 품질 통과
  → 설정 시간 유지
  → 자동 촬영
  → "페이지를 넘겨주세요"
  → 다음 페이지 감지
  → 반복
  → 완료
  → 1/2페이지 분리 + 원근/곡면 보정
  → 기준 페이지 크기로 정규화
  → OCR
  → 중복 후처리 검사
  → 검색 가능한 PDF 생성/갱신
```

## 새 책의 촬영 설정

`책 스캔 → 촬영 카메라`에서 다음을 선택할 수 있습니다.

- **카메라 방식**
  - 책 자동 카메라
  - 기본 문서 스캐너
- **자동 촬영** ON/OFF
- **자동 촬영 대기 시간**
- **최소 품질 점수**

자동 카메라가 특정 책이나 환경에서 잘 맞지 않으면 기본 문서 스캐너로 즉시 전환할 수 있습니다.

- 일시정지/이어읽기/속도 조절

## 데이터 호환

- v0.9은 기존 v0.8 이하 `Library.json`, `pages.json`, 스캔 이미지 및 PDF를 그대로 읽습니다.
- 기존 `ScanProfile`에 v0.9 카메라 설정이 없는 경우 `기본 문서 스캐너`로 자동 보완하여 이전 촬영 동작을 유지합니다.
- v0.9에서 새로 만든 책은 카메라 방식/자동 촬영 설정을 책별로 저장합니다.

## 현재 한계

1. 실시간 페이지 감지는 Vision 사각형 검출 기반 **1차 구현**입니다. 배경과 책의 대비가 매우 낮거나 책 외곽이 화면 밖으로 벗어나면 검출이 늦을 수 있습니다.
2. 라이브 중복 억제는 이미지 패턴 유사도 기반입니다. 거의 동일한 양식이 반복되는 책에서는 오판 가능성이 있어, v0.8의 OCR 기반 후처리 중복 검사도 함께 유지합니다.
3. 페이지 넘김 자체를 손가락 모션으로 직접 인식하는 것이 아니라, `직전 페이지와 달라진 화면 → 새 페이지가 안정됨`을 페이지 변경으로 판단합니다.
4. 곡면 보정은 완전한 3D 복원이 아닌 2D 1차 보정입니다.
5. 이미지형 외부 PDF에 텍스트 레이어가 없으면 PDF 전체 OCR 재처리가 아직 필요합니다.
6. 실제 카메라 자동 촬영 감도는 기기/조명/책 종류에 따라 달라질 수 있으므로 실제 iPhone 테스트 후 임계값 튜닝이 필요합니다.
7. 실제 iPhone 설치/서명 검증은 macOS + Xcode가 필요합니다. GitHub Actions에서는 Simulator 빌드 검사를 수행합니다.

## GitHub 업데이트 방법

v0.8 저장소에 v0.9 압축을 푼 뒤 아래 항목을 다시 업로드합니다.

```text
App/
Models/
Services/
Utilities/
Views/
Resources/
BookScannerReader.xcodeproj/
README.md
.gitignore
```

`.github/workflows/ios-build.yml`은 기존과 동일하므로 다시 업로드하지 않아도 됩니다.

커밋 메시지:

```text
Update BookScannerReader to v0.9
```

업로드 후 **Actions → iOS Build Check**가 초록색인지 확인합니다.
