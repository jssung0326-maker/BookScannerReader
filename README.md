# BookScannerReader v0.7

iPhone용 **책 전용 스캐너 + OCR + 검색 가능한 PDF + Reader + 음성 독서** 프로토타입입니다.

## v0.7 핵심 변경 사항

- **음성 읽기 기능 강화**
  - 현재 페이지 읽어주기
  - 현재 페이지부터 책 끝까지 이어읽기
  - 문장 단위로 읽어 다음 문장으로 자동 진행
  - 이어읽기 중 실제 읽는 페이지로 Reader가 자동 이동
  - 일시정지 / 이어읽기 / 중지
  - 읽기 속도 슬라이더 및 설정값 유지
  - 현재 읽는 문장과 전체 문장 진행률을 하단 미니 플레이어에 표시
  - 한글 문장은 `ko-KR`, 영문 문장은 `en-US` 음성을 우선 사용
- **검색 결과에서 바로 음성 읽기**
  - 검색 결과의 스피커 버튼을 누르면 해당 페이지부터 이어읽기 시작
- **페이지 메모 기능**
  - 현재 페이지에 메모 작성/편집/삭제
  - 메모 목록에서 해당 페이지로 바로 이동
  - 스캔 페이지 순서를 바꿔도 PageRecord ID를 기준으로 메모 위치를 자동 보정
  - 스캔 페이지를 삭제하면 연결된 메모도 함께 정리
- **최근 읽은 책**
  - 책을 열 때 `lastOpenedAt` 기록
  - 서재 상단에 최근 읽은 책 최대 4권 빠른 접근 카드 표시
- **읽기 진행률**
  - 서재에서 책별 현재 페이지와 진행률(%) 표시
  - 최근 읽은 책 카드에도 진행률 표시
- **기존 데이터 호환**
  - v0.6 이하 `Library.json`은 `lastOpenedAt = nil`, `readingNotes = []` 기본값으로 그대로 열림
- 앱 버전 `0.7`, 빌드 `7`

## 기존 기능

- 서재(책 목록)
- VisionKit 문서 스캔
- 1페이지 / 펼친 2페이지 촬영 모드
- 펼친 책 좌/우 페이지 자동 분리
- 제본선 자동 검출 및 수동 위치 설정
- 왼쪽→오른쪽 / 오른쪽→왼쪽 읽기 순서
- 좌/우 페이지 독립 원근 보정
- 제본부 그림자/검은 여백 자동 제거
- 곡면(dewarp) 1차 보정 및 강도 조절
- 첫 페이지 비율을 기준 규격으로 저장
- 이후 모든 페이지 동일 크기로 정규화
- 한국어/영어 OCR
- 촬영 품질 1차 검사
- 페이지 썸네일 관리
- 페이지 순서 변경 / 삭제 / 회전
- 특정 페이지만 재촬영/교체
- 스캔 이미지 → 검색 가능한 PDF 생성
- 기존 PDF 가져오기
- PDFKit 기반 Reader
- PDF 세로 스크롤 / 가로 페이지 넘김
- 페이지 직접 이동
- 북마크
- OCR/PDF 전체 검색
- PDF 공유/내보내기
- 사용자 책 데이터는 앱 Documents 폴더에 저장하여 Git 저장소와 분리

## v0.7 읽기 흐름

```text
책/PDF 열기
  → 마지막 읽던 페이지 자동 복원
  → 북마크 / 메모 / 검색
  → 현재 페이지 읽기 또는 현재 페이지부터 이어읽기
  → 읽는 문장 표시 + 속도 조절
  → 문장이 다음 페이지로 넘어가면 Reader도 자동 이동
  → 현재 페이지와 읽기 진행률 자동 저장
```

## 데이터 호환

v0.7에서 `Book`에 다음 필드가 추가됐습니다.

```text
lastOpenedAt: Date?
readingNotes: [ReadingNote]
```

구버전 파일에는 이 필드가 없으므로 아래 기본값을 사용합니다.

```text
lastOpenedAt = nil
readingNotes = []
```

기존 v0.6 서재와 스캔 페이지를 삭제할 필요가 없습니다.

## 현재 한계

1. 음성 읽기의 문장 강조는 이미지/PDF 원문 위 직접 형광표시가 아니라 하단 미니 플레이어에 현재 문장을 표시하는 방식입니다.
2. 한글/영어가 한 문장 안에 매우 복잡하게 섞인 경우 TTS 음성이 완벽하게 자동 전환되지 않을 수 있습니다.
3. 이미지형 외부 PDF에 텍스트 레이어가 없으면 검색/음성 읽기를 위해 별도 OCR 재처리가 필요합니다. 이 기능은 후속 버전에 추가할 예정입니다.
4. 곡면 보정은 완전한 3D 복원이 아닌 2D 1차 보정입니다.
5. 자동 촬영, 페이지 넘김 감지, 손가락 자동 제거는 아직 미구현입니다.
6. 실제 iPhone 설치/서명 검증은 macOS + Xcode가 필요합니다. GitHub Actions에서는 Simulator 빌드 검사를 수행합니다.

## GitHub 업데이트 방법

v0.6 저장소에 v0.7 압축을 푼 뒤 아래 항목을 다시 업로드합니다.

```text
App/
Models/
Services/
Utilities/
Views/
Resources/
BookScannerReader.xcodeproj/
README.md
.gitignore
```

`.github/workflows/ios-build.yml`은 기존과 동일하므로 다시 업로드하지 않아도 됩니다.

커밋 메시지:

```text
Update BookScannerReader to v0.7
```

업로드 후 **Actions → iOS Build Check**가 초록색인지 확인합니다.
