# BookScannerReader v1.0

iPhone용 **책 전용 스캐너 + OCR + 검색 가능한 PDF + Reader + 음성 독서** 앱의 첫 통합 버전입니다.

## v1.0 핵심 변경 사항

- **첫 실행 안내 화면**
  - 책 스캔, 기준 규격 통일, OCR/PDF, 음성 독서 기능을 4단계로 안내
  - 설정에서 언제든 다시 볼 수 있음
- **앱 설정 화면 추가**
  - 새 책의 기본 촬영 모드
  - 책 자동 카메라 / 기본 문서 스캐너
  - 페이지 맞춤 방식
  - 좌→우 / 우→좌 읽기 순서
  - 자동 촬영 여부, 최소 품질 점수, 안정 대기 시간
  - 원근 보정, 제본부 그림자 제거, 곡면 보정 강도
- **새 책 설정 기본값 기억**
  - 설정 화면에서 정한 값을 다음 새 책 생성 시 자동 적용
- **서재 검색 추가**
  - 제목 또는 저자로 책 검색
  - 검색된 목록에서 삭제할 때 다른 책이 삭제되지 않도록 ID 기준 처리
- **책 정보 개선**
  - 스캔 시작 시 제목뿐 아니라 저자 입력 가능
  - 생성되는 PDF의 문서 정보에도 제목/저자 기록
- **오류 처리 강화**
  - 페이지가 없는 PDF 가져오기 차단
  - 서재 저장/삭제 실패를 사용자에게 경고
  - 손상된 Library.json을 읽지 못해도 기존 파일을 임의 삭제하지 않음
- 앱 버전 `1.0`, 빌드 `10`

## 전체 주요 기능

### 책 스캔
- 1페이지 / 펼친 2페이지 촬영
- 펼친 책 좌·우 페이지 자동 분리
- 제본선 자동 탐색 및 수동 조정
- 왼쪽→오른쪽 / 오른쪽→왼쪽 저장 순서
- 페이지별 원근 보정
- 제본부 그림자/검은 여백 제거
- 곡면(dewarp) 1차 보정
- 첫 페이지 비율을 기준 규격으로 저장
- 이후 모든 페이지를 같은 크기로 정규화

### 자동 카메라
- AVFoundation 기반 책 전용 카메라
- 실시간 페이지 외곽 검출
- 페이지 안정도 및 품질 점수 검사
- 안정 상태 유지 시 자동 촬영
- 최소 품질 점수 / 자동 촬영 대기 시간 조정
- 같은 페이지 반복 자동 촬영 억제
- 수동 셔터 및 조명 제어
- 기본 VisionKit 문서 스캐너로 전환 가능

### OCR / PDF
- 한국어 + 영어 OCR
- OCR 문장 위치 저장
- 검색 가능한 PDF 생성
- PDF 제목/저자 메타데이터 저장
- 기존 PDF 가져오기
- PDF 공유/내보내기

### 페이지 관리
- 페이지 썸네일 관리
- 페이지 삭제 / 회전 / 순서 변경
- 특정 페이지만 재촬영하여 교체
- 이어 스캔
- 촬영 품질 경고
- OCR + 이미지 기반 중복 페이지 검사
- 페이지 수정 후 PDF 재생성

### Reader
- PDFKit 기반 읽기 화면
- 세로 스크롤 / 가로 페이지 넘김
- 페이지 직접 이동
- 읽던 위치 자동 저장
- 최근 읽은 책 및 진행률
- 북마크
- 페이지 메모
- OCR/PDF 전체 검색 및 결과 페이지 이동

### 음성 읽기
- 현재 페이지 읽기
- 현재 페이지부터 책 끝까지 이어읽기
- 일시정지 / 이어읽기 / 중지
- 읽기 속도 조절
- 현재 읽는 문장 및 진행률 표시
- 검색 결과 페이지부터 음성 읽기

## 기본 사용 흐름

```text
새 책
  → 제목/저자 입력
  → 1페이지 또는 2페이지 촬영 선택
  → 책 자동 카메라 또는 문서 스캐너 선택
  → 촬영
  → 페이지 분리/원근·곡면 보정
  → 첫 페이지 기준 크기 설정
  → 모든 페이지 규격 통일
  → OCR
  → 검색 가능한 PDF 생성
  → 서재 등록
  → 읽기 / 검색 / 북마크 / 메모 / 음성 읽기
```

## 데이터 저장

사용자가 스캔한 책, 이미지, OCR 결과와 PDF는 앱의 Documents 영역에 저장됩니다. GitHub 저장소에는 소스코드만 저장하도록 구성되어 있습니다.

기존 v0.2~v0.9에서 만든 서재와 책 데이터는 계속 읽을 수 있도록 호환 기본값을 유지합니다.

## 현재 확인이 필요한 부분

GitHub Actions의 iOS Simulator 빌드는 코드 컴파일 여부를 확인합니다. 다음 항목은 실제 iPhone에서 최종 점검이 필요합니다.

1. 자동 촬영 감도와 흔들림 임계값
2. 책 종류별 제본선 탐지 정확도
3. 실제 곡면 보정 결과
4. 손가락/강한 반사/그림자 환경에서의 품질 검사
5. 장시간 연속 촬영 시 발열과 배터리 사용량
6. 매우 큰 책/PDF의 저장공간과 처리 속도

## GitHub 업데이트 방법

v0.9 저장소에 v1.0 압축을 푼 뒤 아래 항목을 다시 업로드합니다.

```text
App/
Models/
Services/
Utilities/
Views/
Resources/
BookScannerReader.xcodeproj/
README.md
.gitignore
```

`.github/workflows/ios-build.yml`은 기존과 동일하면 다시 업로드하지 않아도 됩니다.

커밋 메시지:

```text
Update BookScannerReader to v1.0
```

업로드 후 **Actions → iOS Build Check**가 초록색인지 확인합니다.
